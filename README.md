# Campus-Service-Portal-Frontend clone

This project is a recreation of a portal for purposes of practicing and getting a better understanding of Laravel.

It was completed as an Advanced Web Application Development assignment. The provided `campus-service-portal-frontend` repository and a set of assigned Laravel development videos were used as the main resources for recreating the system.

## What Was Done

* Set up the provided Campus Service Portal frontend within a Laravel project.
* Converted the provided frontend pages into Laravel views.
* Created and configured the Home page.
* Created and configured the Contact page.
* Set up Laravel routes to navigate between the different pages.
* Connected the Contact page and its form to the Laravel application.
* Set up a MySQL database named `mosh`.
* Configured the Laravel project to connect to the `mosh` database.
* Created the required database structure using Laravel migrations.
* Created the necessary model and controller for handling Contact form data.
* Connected the Contact form to the database so that submitted information is saved.
* Tested the Contact form to ensure that submitted data is successfully stored in the database.
* Tested the application to ensure that the pages, routes, form, and database connection work correctly.
